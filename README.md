# Raafay's March Break 2026

Planning March break activities for Raafay (age 4, turns 5 in September). Based in the Toronto / GTA area. March break runs **Monday March 16 – Friday March 20, 2026**.

## Repo Structure

| File | Purpose |
|------|---------|
| [`schedule.md`](schedule.md) | Day-by-day schedule for the week |
| [`activities.md`](activities.md) | Activity database — ideas, details, status |
| [`inbox.md`](inbox.md) | Drop zone for raw links & notes to be processed |

## How to Use (Claude Code Workflow)

1. **Add raw ideas**: Paste links, notes, or half-baked ideas into `inbox.md`
2. **Process**: Ask Claude Code to process the inbox — it will extract details, add entries to `activities.md`, and clear processed items
3. **Research**: Ask Claude Code to find new activities — it reads `activities.md` first to understand what's already collected and what categories need more options
4. **Schedule**: Ask Claude Code to suggest a schedule or slot an activity into `schedule.md`
5. **Update**: As plans firm up, ask Claude Code to move activities from "idea" to "confirmed" and update the schedule
